# Logos

Coloca aquí los archivos de logo de la marca (no se versionan las imágenes finales, solo esta guía):

- `logo.svg` / `logo.png` — logo principal (usado en el Navbar).
- `logo-alt.svg` / `logo-alt.png` — logo alternativo (monocromo / footer / fondos claros).
- `favicon.ico` — favicon del sitio (también se coloca una copia en `/app/favicon.ico`).

Formato recomendado: SVG para el logo principal (escala sin pérdida), PNG con fondo transparente como respaldo.

Mientras no exista el archivo, los componentes deben usar un *fallback* textual (nombre de la marca), igual que en el mockup original (`brand-fallback`).
